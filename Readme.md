# Streamline

This repository contains independently runnable applications:

- `frontend/` — React + Vite creator studio
- `backend/` — Express API, MongoDB implementation, and Prisma/MySQL schema

## Run the frontend

```powershell
cd frontend
npm install
npm run dev
```

## Run the backend

```powershell
cd backend
npm install
npm run dev
```

The backend reads `backend/.env`; the frontend reads `frontend/.env`.
